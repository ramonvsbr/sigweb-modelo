# Documentação

Será publicada como site estático (HTML, CSS e JS) a partir desta pasta,
por exemplo com o GitHub Pages (Settings → Pages → Branch `main`, pasta `/docs`).

Páginas previstas:

- Arquitetura da aplicação
- Modelagem do banco de dados
- Procedimentos de geoprocessamento
- Registro metodológico
- Manual do usuário (produtores, técnicos e pesquisadores)
